三道の切札 オンライン対戦 v7.0

【起動方法】
1. Node.js (18以上) をインストール
2. このフォルダでターミナルを開き「npm install」を実行
3. 「npm start」を実行
4. ホストPCで http://localhost:3000 を開く
5. 「部屋を作る」を押し、招待URLを相手に送る

【別々のPCから遊ぶ場合】
招待URLが localhost のままでは相手からアクセスできません。
RenderなどNode.jsを実行できるホスティングサービスにこのフォルダをデプロイして公開URLを使うか、LAN内なら localhost をホストPCのLAN IPに置き換えてください。
インターネット越しに自宅PCを公開する場合はネットワーク設定と安全対策が必要です。

【注意】
・サーバーが起動している間のみ接続可能です。
・各部屋は2名まで。赤が先手、青が後手です。
・同期方式は試作です。通信切断時の復帰や不正操作対策は未実装です。
・ゲーム状態には両者の手札情報が含まれるため、厳密な秘匿対戦には未対応です。
・オンライン中はチュートリアルと操作の取り消しを利用できません。
